# 特定のエージェントに縛られない、MCP(Model Context Protocol)準拠の道具サーバーと、それに接続するクライアントの実装


## 機能

- サーバー: clock(現在時刻を取得するツール)、get_wheather(指定された郵便番号の現在の天気を取得するツール)、read_file(許可されたフォルダ内のファイルを読めるツール)、web_search(WEB検索をするツール)を、MCPプロトコル経由で公開
- クライアント: サーバーに接続し、Claudeと対話しながら道具を呼び出す(ステップ数上限・コスト上限つき)

## セットアップ

```
uv sync
```

`.env.example` を `.env` にコピーし、実際のAPIキー(`ANTHROPIC_API_KEY`)を設定してください。

## 使い方

- uv run mcpserver.py
サーバー単体を起動する。
- uv run mcpclient.py mcpserver.py
クライアントから接続する。

## 設計判断

- ひとつのサーバーに複数の道具をまとめる設計にして扱いやすくした。
- 実務ではあまりかかれないクライアント側も一度書くことで理解を深めた。
- stdio方式のサーバーではprint()は通信に割り込み危険なので使わなかった。
- クライアントについては公式のクライアントサンプルコードを参考にしたが、一回のやり取りでツールを一回までしか呼べない問題を改善した。コスト計算も導入した。
